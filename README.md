# Круг — лендинг

Статический сайт на Astro и Tailwind CSS 4 по согласованному варианту «Тёплое».

## Запуск

Требуются Node.js 24+ и pnpm.

```sh
pnpm install
pnpm dev
```

Адрес: http://127.0.0.1:4321

## Сборка и проверка

```sh
pnpm build
pnpm preview
```

Сборка находится в `dist/`. Одновременно запускайте только один сервер на порту 4321.

## Файлы

- `design/` — согласованные макеты, тексты и описание дизайна.
- `src/components/` — блоки страницы.
- `src/styles/tokens.css` — палитра и шрифты.
- `src/styles/global.css` — адаптивная вёрстка и подключение Tailwind CSS 4.
- `src/config.ts` — общий адрес приложения для всех CTA.

Сейчас кнопки ведут в локальную CRM на http://127.0.0.1:3000. Перед публикацией замените адрес в `src/config.ts` на HTTPS-домен приложения. Самой CRM для работы кнопок нужен отдельный запущенный сервер. Лендинг не обращается к базе и не содержит настоящих контактов.


## Автовыкатка на provansov.ru

Push в `main` запускает GitHub Actions: установка по lockfile, сборка Astro в `dist/`,
`rsync` с удалением устаревших файлов только в папке лендинга, проверка главной по HTTPS.
Проверка подтверждает HTTP 200, SHA отправленного коммита в метаданных HTML и ссылки
на `https://app.provansov.ru`. На сервере сборки нет, nginx раздаёт статические файлы.

Для новой версии измените исходники, сделайте коммит и `git push origin main`.
Дождитесь зелёного запуска Deploy landing во вкладке Actions. Если запуск красный,
исправьте ошибку и отправьте новый коммит: отдельного стенда и автоматического отката нет.
Во время синхронизации возможен короткий промежуток с файлами разных версий.

Сервер: `82.146.57.196`, каталог `/var/www/krug-landing`.
Отдельный SSH-ключ хранится в GitHub Secrets `DEPLOY_SSH_KEY`; публичный ключ
установлен с forced command `rrsync -wo -munge`, ограничивающим запись этой папкой.
Ключ не разрешает shell, чтение файлов с сервера и проброс портов. Ключ сервера
закреплён в `DEPLOY_KNOWN_HOSTS`. CRM и её база этим workflow не управляются.

Первичная настройка: человек запускает `sudo bash deploy/install.sh` на сервере.
Это устанавливает rsync и передаёт папку лендинга пользователю crmapp; изменений nginx нет.
Новые значения `.env` для статического лендинга не требуются.
