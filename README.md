# Круг — лендинг

Статический сайт на Astro и Tailwind CSS 4 по согласованному варианту «Тёплое».

## Запуск

Требуются Node.js 24+ и pnpm.

```sh
pnpm install
pnpm dev
```

Адрес: http://127.0.0.1:4321

## Сборка и проверка

```sh
pnpm build
pnpm preview
```

Сборка находится в `dist/`. Одновременно запускайте только один сервер на порту 4321.

## Файлы

- `design/` — согласованные макеты, тексты и описание дизайна.
- `src/components/` — блоки страницы.
- `src/styles/tokens.css` — палитра и шрифты.
- `src/styles/global.css` — адаптивная вёрстка и подключение Tailwind CSS 4.
- `src/config.ts` — общий адрес приложения для всех CTA.

Сейчас кнопки ведут в локальную CRM на http://127.0.0.1:3000. Перед публикацией замените адрес в `src/config.ts` на HTTPS-домен приложения. Самой CRM для работы кнопок нужен отдельный запущенный сервер. Лендинг не обращается к базе и не содержит настоящих контактов.
